# 本书的使用方式

## 按角色读

- **应用开发**：从第五部分实践章入手（启动、渲染、内存、I/O、功耗），遇到机制不懂再回第一部分。
- **系统/ROM 开发**：第一、四部分是主线，工具章（13-16）讲证据形态。
- **性能测试与质量**：第二、三部分是主线，配合附录 C 的 Trace 点速查和附录 D 的 Checklist。
- **从 Android 转过来的工程师**：先读第 1、2、5 章建立概念映射（Binder↔IPC、Choreographer↔Vsync 驱动、Perfetto↔HiTrace），再按问题读其余章节。

## 按问题读

| 现象 | 先读 |
| --- | --- |
| 滑动卡、掉帧 | 第 7 章 → 第 2 章 → 第 20 章 |
| 点击后页面出来慢 | 第 8 章 → 第 19 章 |
| 应用无响应弹窗 / AppFreeze 日志 | 第 9 章 → 第 5 章 → 第 15 章 |
| 内存持续上涨、闪退 OOM | 第 10 章 → 第 4 章 → 第 21 章 |
| 耗电快、发热 | 第 11 章 → 第 23 章 |
| 启动慢 | 第 19 章 → 第 14 章 Launch 会话 |
| 不知道用什么工具 | 第 16 章 → 第 13、14 章 |

## 关于版本

正文结论默认覆盖 HarmonyOS 6.x / API 20+，并向上标注变化起点（如"API 12 起"、"API 18 起"）。机制源码引用 OpenHarmony 6.0 主干；厂商闭源差异在第 18 章说明。
