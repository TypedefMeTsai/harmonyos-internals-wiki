# 适用读者

这本书假设你已经会写 ArkTS/ArkUI 应用，知道 Stage 模型和 Ability 的基本概念。它不讲"怎么搭一个页面"，讲的是"页面背后的系统是怎么工作的、出了问题怎么查"。

适合：

- 有 1 年以上鸿蒙开发经验，开始被性能问题追着跑的工程师。
- 有 Android Framework / 性能分析经验，需要把方法论迁移到鸿蒙的工程师。
- 负责应用质量、稳定性与体验验收的测试和 SRE 同学。
- 做 OpenHarmony 系统或三方发行版，需要理解上层行为边界的系统工程师。

不适合：

- 零基础学鸿蒙开发（请先看官方快速入门）。
- 找 API 用法大全（请看官方 API 参考）。
